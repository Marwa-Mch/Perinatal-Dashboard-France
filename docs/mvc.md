# Architecture MVC

Les vues Streamlit reçoivent les choix et affichent les résultats. Les contrôleurs valident les sélections et coordonnent les modèles. Les modèles accèdent aux CSV, aux bases SQLite et à TinyDB. Streamlit exécute ces couches dans une même application Python. Voir conception.md pour les schémas, exemples et limites de la séparation actuelle.
